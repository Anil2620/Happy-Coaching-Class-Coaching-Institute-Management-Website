# Happy Coaching Class

A responsive coaching institute website for students from Class 5 to Class 12 in Odisha.

## Included

### Public pages
- Home
- About
- Classes
- Subjects
- Courses
- Teachers
- Batches
- Study Materials
- Notices
- Gallery
- Results
- Contact / Enquiry

### Admin pages
- Login
- Dashboard
- Students & Enquiries
- Teachers
- Courses
- Notices
- Materials
- Gallery

## Technologies

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts
- LocalStorage demo
- Firebase-ready structure

## Run locally

1. Open the project folder in VS Code.
2. Install the Live Server extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

## Firebase next step

Create a Firebase project and enable:
- Firebase Authentication
- Cloud Firestore
- Firebase Storage

Then replace the placeholders in `js/firebase.js` and implement Firebase Auth/Firestore/Storage operations.

## Important

The following are sample placeholders and should be replaced with real institute data:
- Phone number
- Address
- Email
- Teacher names and qualifications
- Batch timings
- Student statistics/results
- Photos
- Notices
- Study materials
